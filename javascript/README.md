# Meetup component of Event Integrations

JavaScript group/topic reads, token-response normalization and injected transports. Python has a broader event-operation API. Callers supply configuration, authorization and transport.

Build a local package with `npm pack --ignore-scripts`. The public
[developer guide](https://github.com/Mathist-Consulting-LLC/meetup-integration-public/blob/main/docs/README.md)
links installation, API contracts, synthetic examples and recovery responsibilities.
